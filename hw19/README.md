
# AI Chat Application

Проект представляет собой веб-приложение для общения с нейросетью, построенное на микросервисной архитектуре. Система включает в себя аутентификацию пользователей, веб-интерфейс для чата и устойчивое хранение истории переписок.

## 🏗 Архитектура проекта

Система состоит из четырех взаимосвязанных модулей:

1.  **Модуль нейросети (Ollama)** - Сервис искусственного интеллекта.
2.  **Входной шлюз (Ollama-Security)** - Центральный узел для аутентификации и маршрутизации.
3.  **Модуль интерфейса чата (Ollama-UI)** - Веб-интерфейс и логика взаимодействия с AI.
4.  **Модуль хранения данных (Ollama-Data)** - Сервис для сохранения истории чатов.

## 🚀 Быстрый старт

Следующие шаги позволят вам запустить весь проект одной командой.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <your-repository-url>
    cd <project-directory>
    ```

2.  **Запустите все сервисы с помощью Docker Compose:**
    ```bash
    docker-compose up -d
    ```
    Эта команда развернет все необходимые базы данных и сервисы.

3.  **Приложение будет доступно по адресам:**
    *   Шлюз и регистрация: http://localhost:8080
    *   Интерфейс чата: http://localhost:8081
    * (Сервисы хранения данных и нейросети являются внутренними)

📖 Использование

    Откройте в браузере http://localhost:8080.

    Зарегистрируйте нового пользователя, используя форму регистрации.

    После успешной регистрации и авторизации вы будете автоматически перенаправлены на интерфейс чата по адресу http://localhost:8081.

    Начните общение с нейросетью. Ваши сообщения и ответы будут сохраняться в базе данных.

🔧 Конфигурация

Основные настройки каждого сервиса можно найти в соответствующих файлах application.yml или application.properties.
API Gateway

    server.port: 8080

    Настройки подключения к PostgreSQL: spring.datasource.url, username, password

    Настройки Spring Security: JWT, пароли и т.д.

Chat UI Service

    server.port: 8081

    Ссылка на Ollama: ollama.url=http://localhost:11434

    Ссылка на Storage Service: ollama-data.url=http://localhost:8082

Data Storage Service

    server.port: 8082

    Настройки подключения к MongoDB: spring.data.mongodb.uri

🗄 Базы данных

    PostgreSQL: Хранит учетные данные пользователей (логины и хэши паролов). Таблица users.

    MongoDB: Хранит историю чатов. Коллекции topics (темы чатов) и messages (сообщения внутри чатов).

🛠 Технологии

    Backend: Java 17+, Spring Boot, Spring Security, Spring WebFlux, WebClient

    Базы данных: PostgreSQL, MongoDB

    AI: Ollama (контейнеризован в Docker)

    Бuild Tool: Maven

    Контейнеризация: Docker, Docker Compose
